# 💰 Expense Tracker Application

A professional desktop Expense Tracker application developed using Python, Tkinter, SQLite, and Matplotlib.

---

## 🚀 Features

- 🔐 Secure Login & Signup System
- 🔑 Password Hashing using bcrypt
- 💸 Expense Management
- 💰 Income Tracking
- 📊 Expense Charts & Analytics
- 📅 Monthly Reports
- 🔍 Search & Filters
- 📄 CSV & PDF Export
- 👤 Profile Management
- 🌙 Dark/Light Theme
- 💾 Backup & Restore System

---

## 🛠 Technologies Used

- Python
- Tkinter
- SQLite3
- Matplotlib
- bcrypt
- ReportLab
